# Multiple Crop Disease Prediction using Deep Learning

This repository implements a stacked convolutional neural network (CNN) to predict multiple diseases in crop leaves using the [PlantVillage](https://www.kaggle.com/datasets/mohitsingh1804/plantvillage) dataset. The model attains 98.28% test accuracy, with precision, recall, and F1-score all exceeding 98%, demonstrating its effectiveness for real-time, scalable agricultural disease monitoring.

For detailed methodology, experiments, and theoretical background, see the [Jupyter Notebook](multiple-disease-prediction.ipynb) and the [full documentation](Multiple_Crop_Disease_Prediction.pdf).
